How this is made

Every ranking on kWh Ranked is generated by code from the public dataset named in its Sources section. The steps are the same for every page:

  1. Data. The dataset is downloaded from its publisher (the retrieval date is the page's Updated date). We do not type numbers in by hand.
  2. Selection. A per-page recipe states which products qualify (e.g. a capacity range), which criteria count and how much each weighs. The weights are printed on the page.
  3. Scoring. Code scores each value against the best on the page and adds up the weighted results (how we rank). Pros and cons are the product's strongest and weakest criteria among those compared, also computed.
  4. Writing. The explanatory text (introduction and FAQ templates) is drafted with the help of an AI model (Anthropic's Claude) and filled with numbers computed from the data. No AI model chooses a product, sets a score or supplies a number.
  5. Checks. The build refuses any page with fewer than 3 products, a criterion missing for any product, weights that do not sum to 100%, no sources, or an undated price.
  6. Refresh. Each page shows its next refresh date; the data is downloaded again and the page rebuilt on that schedule.
  7. Open data. Each ranking table can be downloaded as CSV or JSON from its page.

Corrections: see About. Money: see the disclosure; commissions never change a score.
